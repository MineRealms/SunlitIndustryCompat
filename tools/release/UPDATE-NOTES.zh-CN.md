这是现有整合包的累计差分，不是完整游戏。文件逐项 SHA-256 见 UPDATE-MANIFEST.json / SHA256SUMS.txt；服务端差分仅含相对本次 ROSETTA 检查有变化的文件。

## 安装

1. 完整退出相应客户端，或正常保存并停止服务器。先备份将替换的 mods、config、kubejs；不要在游戏运行时替换 JAR。
2. 将旧的 sunlit-industry-compat-1.20.1-*.jar 移到 mods 外的备份目录，再覆盖差分文件。mods 内仅保留一个 0.8.0 正式版。不要恢复 WorldEdit。
3. 配置模板记录本次发布的默认策略。若自己修改过相同选项，请逐项合并；新实验保持 false。不要覆盖个人 options、光影和画质配置。
4. 客户端完整重启；服务端在约定维护窗口安装后完整重启。仅 /reload 无法加载新 Java 类、Mixin 或启动注册内容。
5. defaultconfigs/zmod-industrial-machines.toml 是新世界模板；现有世界使用自己的 serverconfig，本差分不覆盖存档配置和玩家进度。

## 验证边界

0.8.0 JAR 与已通过最后一次隔离服验证的成品完全一致：65 个单元测试通过，18 模组精简服正常启动，配方数 42,493，默认关闭 / 主开关回退及资源、单元格恢复探针通过。此前阶段做过方法级 benchmark，不能把它换算成服务器 TPS 或客户端 FPS。本次交付不新增性能结论，未测客户端光影与大型基地帧率。

生产服务器上传只暂存更新，不代表已激活。上传期间不停止服务器、不执行资源重载；重启安装前检查 SERVER-BEFORE.json 与在线文件是否继续变化。服务器正在使用的旧 JAR 不能热替换。

差分不含 token、HMCL 账号、更新器配置、日志、缓存、存档或测试服务端。
